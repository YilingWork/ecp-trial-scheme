✓ 對本試辦方案的可能用途

  • 第 3 章（藥局條件與試辦區域）：可作為理解「社區藥局既有服務標記制度」之現成範例——全聯會已有一套將藥局特色（戒菸、無障礙、送藥到宅、教學認證）結構化上架的運作模式，試辦藥局若需對外標示，可評估沿用既有欄位或新增標記，而非另建系統。
  • 第 10 章（醫療轉介）／第 11 章（衛教資源）：民眾端「找到附近藥局」之現成入口；若試辦上路後需讓民眾查得「哪些藥局有參與試辦」，此平台為可評估之既有載體。
  • 無障礙欄位（6 項）之顆粒度相當細，對可近性論述（含身心障礙者取得管道）具參考價值。

依「民眾實際遇到狀況時的順序」編排：30 秒重點摘要 → 快速決策表 → ①需不需要緊急避孕 → ②時效 → ③第一代與第二代如何選 → ④在台灣如何取得 → ⑤服用方法 → ⑥接回規律避孕 → ⑦追蹤要點 → ⑧驗孕時機 → ⑨哺乳 → ⑩與事前避孕藥比較 → ⑪危險徵象 → 常見迷思 → 常見問答 → 參考依據。〔3〕

該文章之主要陳述（引述，非本計畫立場）

時效：第一代 Levonorgestrel（LNG）「建議 72 小時內」；第二代 Ulipristal acetate（UPA）可到「120 小時內」；銅製子宮內避孕器「5 天內」由醫師放置。〔3〕
效果：該文引述 LNG「常被引用的效果約為 24 小時內 95%、24～48 小時 85%、49～72 小時 58%」；UPA 部分引用美國食品藥物管理局（FDA）仿單之觀察懷孕率。文章同時強調此為族群層級之統計，非個人保證成功率，並列出影響因素（服藥前已排卵、服藥太晚、身體質量指數〔BMI〕較高、併用影響藥效之藥物、服藥後再度無防護性行為）。〔3〕
作用機轉：「主要作用是延後或抑制排卵，不是墮胎藥，也不會中止已經著床的懷孕」，並明確區分於 RU486（mifepristone，米非司酮）。〔3〕
副作用：噁心、頭痛、乳房脹痛、腹痛、疲倦、點狀出血，且「比較容易造成月經提前、延後、經量變多或變少」；服藥後 2～3 小時內嘔吐建議聯絡醫師或藥師，通常需補服一劑。〔3〕
取得方式：「目前在台灣，第一代與第二代事後避孕藥都屬於處方藥」，須醫師評估開立處方、藥師調劑；文章並自行加註「藥品分級與取得方式可能隨政策或公告改變；實際仍以衛福部食藥署最新公告、藥品仿單與醫療院所現場作法為準」。〔3〕
哺乳：LNG「一般可正常哺乳」；UPA「因哺乳資料較有限，常建議服藥後暫停哺乳約 5～7 天」。〔3〕
紅旗徵象：驗孕陽性、單側下腹痛、大量出血、頭暈快昏倒、肩膀痛→直接就醫，以排除子宮外孕或腹腔內出血。〔3〕
