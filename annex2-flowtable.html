附件二　藥局供應緊急事後避孕藥（ECP）評估與轉介流程表

兩階段評估之逐項判斷準則與衛教清單

藥局辨識民眾是否可購買緊急事後避孕藥之評估與轉介流程表

試辦藥品以 LNG（Levonorgestrel）為限。

流程分兩階段： 階段一・線上評估（民眾自行上網填寫，採全部填完後一次評估，填畢後就不符項目給予提示與就醫指引；符合禁忌症或有須就醫情形者，於線上導引就醫，不產生購藥條碼，毋須前往藥局） → 階段二・到藥局現場（本人持條碼到試辦藥局，核對政府核發證件後現場評估、供藥）。

處置類別之名稱與定義

類別 標示 正式名稱 定義
第一類 🔴 ■ 逕行轉介 符合禁忌症者、驗孕陽性、異常陰道出血、逾 72 小時或 72 小時內已服用過本藥者，不予供應藥品，逕行轉介婦產科或其他設有婦產科之醫療機構，並開立醫療轉介單。
第二類 🟡 ▲ 供藥後轉介或通報 以預防懷孕為第一優先，先行供應藥品，另依個案情形加強衛教，並視需要轉介醫療機構或依法通報。
第三類 🟢 ● 一般供藥 各項檢核均無須轉介或通報之情形，供應藥品並依系統帶出之個人化清單逐項執行標準衛教後結案。
本類包含需加強衛教、惟不觸發轉介或通報之情形。
第四類 ⚪ ◆ 不符親領要件，不予供藥 到場者與線上填答者、證件本人不一致（代購或證件不符），本試辦不予供應；告知得依現行程序至醫療院所就醫取得。

階段一・線上評估（民眾自行上網填寫，尚未到藥局）

填答呈現方式：採全部填完後一次評估，不採逐題中斷式，避免反覆試填與修改答案；填畢後就不符項目給予提示與就醫指引。命中任一 🔴 者，系統告知就醫、不產生購藥條碼。評估順序：年齡 → 禁忌 → 懷孕 → 出血 → 時效 → 重複服用。

步驟 判斷 處置

# 檢核項目 詢問／判斷方式 處置
1 對 LNG 成分過敏 詢問過敏史 「是」→ 🔴 逕行轉介（本試辦僅 LNG、無替代品項）。
答「不確定」者不逕予拒絕供藥：條碼照常產生並附「過敏史待確認」註記，由藥師現場詢問確認
2 嚴重肝功能障礙 依國內仿單禁忌詢問病史 「是」→ 🔴 逕行轉介（禁忌症）。答「不確定」者不逕予拒絕供藥，附「病史待確認」註記由藥師現場確認。「嚴重肝功能障礙」指肝硬化、肝衰竭、黃疸、腹水；B 肝帶原、輕度肝功能異常、脂肪肝不屬此列，得正常供藥

四、❷ 懷孕可能性評估（含「3 週驗孕」判斷準則）

僅「有懷孕可能之相關情況」且「3 週前曾發生無防護性行為」之族群才需建議驗孕。

步驟 詢問／判斷方式 處置
① 相關情況 是否有懷孕可能之相關情況（週期不規則／末次月經已逾週期／末次月經不確定〔經量少、週期短〕／產後流產後月經未恢復）？ 無相關情況 → 續問 ❸（不需驗孕）；有相關情況 → 續下
② 3 週驗孕 有相關情況者再問：距今「3 週以前」是否曾發生無防護性行為？ 否（僅近 3 週內發生）→ 不需驗孕、可給藥（服用前追加「不排除本次之前懷孕之可能」說明）；是 → 續下（驗孕）
③ 驗孕結果 3 週前曾有性行為者 → 建議使用驗孕棒 陽性 → 🔴 逕行轉介（不予供藥）、轉介婦產科
陰性 → 續問 ❸
不願驗孕 → 🟡 供藥（不因不願驗孕而拒絕供藥）＋下列告知與追蹤

4-1　不願驗孕者之處置

詢問方式與前提情境：

  • 本題之觸發條件：僅「勾選任一有懷孕可能之相關情況（週期不規則／逾期未至／上次月經量少或天數短／產後・流產後月經未復）＋距今 3 週（21 天）以前曾發生無防護性行為」之族群，線上問卷才會出現驗孕建議題（06 問卷 3-3）；其餘民眾全程不會被詢問驗孕事項。到藥局時，藥師僅對條碼附「待驗孕」註記者確認結果；民眾已在線上自主選擇，藥局端不重新勸說驗孕。
  • 到藥局確認話術：
    • 開場（中性、不批判）：「問卷有提到驗孕的部分，跟你確認一下，這不影響你今天買藥，只是讓我把該提醒的事項說清楚。」
    • 選「到藥局告訴藥師」者：「你有驗孕結果嗎？需要的話藥局有驗孕棒可以現場使用。」→ 陰性：照常供藥；陽性：現場轉介婦產科（不供藥）；當場改為不願驗孕：依下列辦理。
    • 選「我不想驗孕」者：不追問原因、不重複勸說，直接進入告知：「沒問題，藥一樣可以給你。有四件事請你一定要記得：」（即下列告知 1–4，逐項確認）。
  • 禁止事項：以驗孕作為供藥條件；質問「為什麼不驗」；於其他顧客可聽聞處詢問驗孕或性行為相關問題（必要時以「到旁邊跟你確認用藥資訊」引導至半隱私空間）。

供藥時應完成之告知（納入個人化衛教清單）：

  1. 若已確定懷孕，即不需服用本藥；本藥對已成立之懷孕無效，亦無法終止懷孕。
  2. 若疑似懷孕，務必注意後續追蹤：可能於本次之前即已受孕而不自知（例如 5 天前曾有不安全性行為、未全程使用保險套），本次又有未受保護之性行為而前來服藥，惟本藥對已成立之懷孕並無效果。
  3. 月經未按預期時間到來，或出現亂經，此情境仍可供藥，供藥後建議至婦產科就醫確認。
  4. 服藥後約 3 週建議驗孕或回診確認避孕成功。

追蹤要求：本試辦及未來正式制度均無強制民眾就醫之權力，經建議轉介者仍可能不就醫。本試辦不另建立個案層級之就醫追蹤名單機制；經建議轉介者之後續就醫情形，以追蹤問卷二之自陳資料統計呈現，累積資料供未來政策參考。

問① 最後一次月經什麼時候？ 續下
問② 該次出血與平常月經有無不同（量、天數、顏色）？ 續下
判定 與平常不同、無法明確說明，或當下正在出血且無法判斷是否為月經 🔴 不供藥、轉介婦產科查出血原因（無法說明清楚即視為異常；排除子宮外孕、子宮內膜病變等，出血鑑別屬醫師專業）；合併急性徵象（單側下腹劇痛、面色蒼白冒冷汗）→ 視為急診，逕送設有婦產科之急診

六、❹ 時效窗口（距最近一次未受保護性行為之時數）

時數 判定 處置
72 小時內 LNG 有效 通過線上篩選（時效以購藥條碼效期為準，藥局現場不另重算）
72–96 小時 LNG 屬仿單外使用，無可靠療效數據 🔴 逕行轉介，不予供藥；逾 72 小時之效果未知（國內仿單：24 小時 95%／48 小時 85%／72 小時 58%／逾 72 小時未知），逾時者於線上即導引就醫，不產生購藥條碼
超過 96 小時 LNG 已無效 🔴／轉介婦產科評估 UPA（120 小時內）／含銅子宮內避孕器（5 日內），口頭告知剩餘時數之急迫性

此為「效果」而非「安全」判斷準則。距性行為 72 小時內始供藥。線上初篩逾 96h 即導引就醫、不產生條碼。 ⚠️ 條碼效期起算點：民眾於本題所填之性行為發生時間，即為購藥條碼效期之起算點（條碼自該時點起 72 小時內有效），藥局現場不再重算時效，以條碼效期為準。 通過 ❶–❺ → 系統產生 購藥條碼＋顯示可查詢試辦藥局之介面（民眾自選縣市與行政區）。

七、❺ 重複服用檢核

步驟 詢問／判斷方式 處置
問 在最近 72 小時內，你是否已經服用過緊急事後避孕藥？ 是 → 🔴 不供藥。說明：Levonorgestrel 於 72 小時內服用一次即具效果，該期間內縱有另一次性行為，亦不須再次服用；如有疑慮請洽婦產科。

階段二・到藥局現場（本人持條碼至試辦藥局）

9-1　疑似性暴力／性侵害之辨識判斷準則（藥師端執行工具）

辨識判斷準則屬藥師訓練與執行工具、非民眾衛教內容；現場以觀察為主、非逐案盤問，發現明顯跡象依責任通報辦理。以下納入教育訓練課程七（性侵害辨識與兒少保護，90 分鐘合併一堂）。

觀察面向（任一明顯跡象 → 依 ❼-1 處置：先供藥＋113 通報）：

面向 觀察重點
